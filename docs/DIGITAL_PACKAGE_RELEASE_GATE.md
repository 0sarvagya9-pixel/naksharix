# Digital package release gate
No release or database migration has been performed. All new sales and generation flags default false; existing reports and approved prices are unchanged. Offer JSON requires exact product key/version and an explicitly approved integer paise price; no default/test price is a live offer.
- Supported products: business-name comparison, five-report Complete Life, three-person Family Kundli, couple compatibility plus wedding-planning workbook, original study workbook. Marriage package does not include human consultation until separately contracted; no external service or prediction is guaranteed.
- Collect only necessary private inputs, validate each subject and explicit consent, save one versioned immutable draft, keep private data out of gateway metadata. All capture and refund transitions use the single existing merchant; per-order advisory locking, exact payment binding, no repeat debit on ambiguous gateway state. Partial refunds suspend access pending review; full refunds revoke.
- Rehearse additive migration, schema and rollback on disposable DB; verify two concurrent checkout attempts, failed order reservation, capture replay, refund while rendering, expired draft, five-attempt recovery, account isolation, exact price and component count. Test all PDF rendering, private storage, delivery, accessibility, mobile and language acceptance before activation.
- No provider, merchant, price or production approval assumed. Workbooks and business name comparison currently English; report components support EN/HI/Hinglish through existing renderer.
