# Partner chart reference PDF (held development)

The new `chart-pdf` scope requires both B2B_INTEGRATION_ENABLED and B2B_CHART_PDF_ENABLED. Existing contracts and keys are not expanded. New licensed contract must explicitly select chart-pdf, the approved per-unit rate and allowance, data-processing permission and expiry. Each successful chart PDF consumes two existing contract units, no automatic charge. The new scope is default off. No new approved pricing or live partner activation is implied.

Use POST /api/partner/v1/calculate, Authorization: Bearer <server key>, JSON {scope:"chart-pdf",requestId:<new UUID>,subjectPermission:true,birth:{date:"1992-05-18",time:"08:15",latitude:28.6139,longitude:77.209,offsetMinutes:330}}. Example inputs are synthetic. Output includes the current contracted brand, two pages of actual numerical chart data, byte length, SHA-256 and Base64 PDF bytes. Client must decode and verify checksum before private delivery. Response is private/no-store; no birth data or PDF persisted in the usage ledger. No client-supplied brand, personal name, image, URL or HTML. Current PDF language English and brand printable ASCII (2–80 characters); licensed custom logos, arbitrary script fonts, custom domains, automated settlement and full personalized editorial report products remain outside this implementation. Existing public reports are unchanged.

Reference: MDN HTTP Cache-Control (private/no-store), existing installed pdf-lib renderer and existing PostgreSQL contract ledger. Synthetic database/handler acceptance and visual render separate from live commercial acceptance.
