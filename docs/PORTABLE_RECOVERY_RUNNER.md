# Manual portable encrypted recovery — independent of Vercel Sandbox

This alternative reuses the existing Neon read-only TLS export, AES-256-GCM envelope, immutable private Vercel Blob paths, same daily lease, and receipt contract. No new scheduler, storage account or provider. It runs only on a dedicated, authorized non-root Linux host with installed PostgreSQL 17 client/server and Node 22, sufficient resources, and the existing securely injected backup credentials. It must never be run with production data on public GitHub CI, shared machine, model environment, or a host whose storage/egress is unapproved. Check existing free resource allowances before any real invocation; do not incur charges.

Set NAKSHARIX_RECOVERY_APPROVAL to OWNER_DEDICATED_HOST only in the trusted host environment. Inject BACKUP_DATABASE_URL (same source, preferably least-privilege read-only role), BACKUP_EXPECTED_SOURCE_HOST, BACKUP_ENCRYPTION_KEY (same existing key), BLOB_READ_WRITE_TOKEN through a protected local secret store. Never put secrets in code, chat, command arguments or logs. Use the existing locked dependencies. Verify PostgreSQL tools are on PATH. Command: node --experimental-strip-types scripts/ops/run-portable-recovery.mjs --execute-private-recovery

The alternate uses a unique private temporary directory, fixed audited export/restore workers, Unix-socket-only restore cluster, immutable uploads, encryption authentication and exact roundtrip checksum, conditional lock/retention cleanup and durable receipt reread. It refuses to override any existing lease or malformed same-day proof. No live payment, email, schema change or production row write. Email acknowledgement remains false because this runner sends no notice. Existing recovery cron/watch remains unchanged. Successful fixture tests are not a production recovery receipt. Production acceptance requires a successful actual dedicated-host run, independently verified existing private endpoint, current schema/row-count evidence and seven-day retention. Until then release hold remains.

Test default synthetic contract: node --experimental-strip-types scripts/qa-portable-recovery.mjs. Existing isolated PostgreSQL reliability rehearsal exercises the actual private-socket restore script on the synthetic encrypted archive and compares exact schema counts and marker rows. No production credentials are passed to CI.
